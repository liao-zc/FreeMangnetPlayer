## 状态定义

- **通过（代码）**：已核对实现路径，尚需 APK/设备操作验证。
- **通过（历史实测）**：有此前设备或 CI 证据，不代表本轮代码回归通过。
- **部分**：逻辑已实现，但验收条件或外部资源条件没有满足。
- **未通过/未测**：有失败证据，或本轮缺少验证环境。

## 历史需求汇总与状态

下列清单合并此前所有会话要求。状态表示最新代码/既有证据，不将界面存在等同于公网功能成功。

### A. 磁力搜索与资源结果

- 搜索框、内置候选搜索源和自定义源；支持编辑/删除、最多 10 个，BDFlix 默认：**代码已有；本轮未实搜点验**。
- 结果留在 App 内，显示文件名并可解析、下载、缓存、收藏：**代码已有；公网可用性部分**。
- 六个指定源可选；结果可按源站翻页、当前结果每页 10 条、结果页跳转：**代码已有；源站缺少翻页元数据时总页数不可得**。
- BTIH 去重、关键词相关性、排序、文件名后标注格式、简洁发布时间：**本轮已改相关性/去重/分页；排序及格式标注已有；时间缺失不可推造；待真源回归**。
- 大小、格式和日期三项字段：**界面字段始终出现，未知显示 `—`；不能保证搜索站点未提供时仍精准显示**。
- 搜索失败时可返回、取消，不停留空白：**已有空/失败/超时状态实现；本轮未 UI 回归**。

### B. BT 解析、下载、缓存与边下边播

- 磁力解析和文件选择、多个文件播放切换、下载单选/多选、复制磁力：**代码已有；本轮未重新验证每种种子**。
- 边下边播、任意位置跳播并优先缓存、缓存可续播、下载/缓存复用数据、后台任务：**代码已有受控种子测试；公网资源结果不能保证**。
- 暂停/取消/删除、缓存和下载管理、多选清理、已下载/缓存视频打开：**代码已有；本轮未设备回归**。
- 无节点时明显持久提示、避免计入有效下载/缓存：**节点状态和库条目标记已实现；本轮仅代码核对**。
- 速度最低 2 MB/s、无节点资源达到 90% 可播：**未满足且不能由客户端保证**。速度取决于种子 Peer、上行能力、路由和运营商；既有公共测试 0/10 首帧。App 未设置人为限速。
- 用户指定 3b1f… Spider-Man magnet：**既有证据显示种子元数据/数据链不满足起播；不能报告已修复**。
- 本轮新 magnet (`3b1f…`, `dn=…srt`, `so=1`)：**未做本机端到端测试**。字幕不是可解码视频；即使下载成功也不算播放成功。

- 多文件下一条优先选择已缓存/已下载文件、切换释放非保留缓存：**代码已有；本轮未真机回归**。
- 缓存进度、资源信息、音轨/字幕按钮：**代码已有；音轨/字幕本轮改为图标；未设备验证**。

## 本轮实施差异

- MainActivity：全局设置入口；哈希去重；标题相关性过滤；结果集本地 10 条分页、翻页和跳页；大小/格式/时间字段改成精简缺省值。
- SettingsActivity：系统返回在设置子页回到设置菜单；磁播专属页不再露出“软件更新”；移除手写过期更新时间。
- TorrentTasks：无 Peer 任务固定为“找不到资源”，暂停并标记后不再周期性覆写下载列表条目。
- IPTV：停用 PlayerView 自带缓冲圈；控制条放到画面下方/全屏底部；选台弹窗浅色、频道名左对齐。
- Player controls：音轨/字幕英文文本替换为图标。

## 验证阻塞与下一步

1. 本机没有 Java/JDK，故本机 Gradle 启动失败；GitHub Actions 已完成实际 Kotlin/资源编译：中间运行先后发现 nullable 类型与缺失 import 编译错误并修正；后续 Android APK 构建及模拟器 UI 工作流通过（[build/UI run 41156594845](https://github.com/liao-zc/OmniPlayer/actions/runs/41156594845)）。
2. Android API 35 模拟器的当前 UI 点检通过（[run 41156594845](https://github.com/liao-zc/OmniPlayer/actions/runs/41156594845)），取得 14 张当前界面截图，见 `docs/screenshots/current-ui/`。本轮尚未发布新 APK。
3. 导航与设置 UI 已通过模拟器；搜索分页算法的本轮 UI 回归、直播播放控件的画面内位置仍未单独自动化。BT 公网起播需分别记录元数据、Peers、校验字节、首帧与持续播放。
4. 新 magnet 的 `dn` 明确是字幕 `.srt`，应先检查 torrent 文件清单及 `so=1` 对应文件；只有选择视频文件并出现视频首帧，才能通过边下边播验收。
