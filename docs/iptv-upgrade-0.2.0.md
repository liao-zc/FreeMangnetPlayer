# OmniPlayer IPTV 升级报告（0.2.0）

## 本次变更

- 应用启动名称改为 **OmniPlayer**；保留 Android applicationId `com.freemangnetplayer`，以免改变既有安装身份和磁力数据位置。
- 首页新增“电视直播”“磁力播放”“统一设置”入口。磁力播放仍进入原有搜索与列表界面，磁力解析和下载实现未替换。
- 新增 IPTV M3U 播放列表读取，默认源为 `https://iptv-org.github.io/iptv/index.m3u`；支持多个自定义源、编辑名称/地址和移除源。
- 识别 M3U 的 `#EXTINF`、`tvg-id`、`tvg-logo`、`group-title` 与频道 URL；按分类筛选、搜索频道、显示频道图标，并为缺少图标的频道显示名称首字母。
- 新增独立的电视台收藏存储，可收藏和取消收藏，并可只浏览收藏频道。
- 新增 Media3 网络直播播放器，包含播放器控制条、横屏全屏切换、Android 画中画入口和返回操作。
- 频道列表提供逐台“测速”操作。结果显示建立 HTTP 响应的耗时（毫秒），这是连接响应时间，不是持续视频吞吐量。
- 设置页明确分为“电视直播设置”和“磁力播放设置”；电视直播子页允许编辑多个源。

## 格式与兼容说明

播放器采用 Media3 的流媒体判别和解码能力。M3U 清单本身只是频道地址索引；可播放性取决于具体地址、协议、服务器访问策略以及设备解码器。HTTP(S) HLS 和常见渐进式流会由 Media3 尝试识别；不能据此保证所有 IPTV 私有协议、DRM、需要特殊请求头的频道、所有 TS 变体或设备不支持的编码均可播放。若源要求账号、特殊 Header 或 DRM，本版没有配置对应能力。

“全屏”使用横屏方向切换；“悬浮”使用 Android 系统画中画，不是任意窗口管理器覆盖层。不同 Android 版本和电视设备对画中画支持不一。

## 后续构建所需

在安装 Java 17 与 Android SDK 35 的环境运行：

```text
gradlew :app:assembleDebug
```

构建成功后还需在手机、Android TV 和平板上分别验证：加载默认源、添加第二源、图标与分类、测速、实际播放、收藏往返、横屏全屏、画中画、返回主页，以及原磁力搜索/播放/下载回归。此报告不把未执行的设备验证描述成通过。
