# FreeMangnetPlayer 使用说明

本文对应当前应用界面。截图由 Android 模拟器运行应用后截取。磁力链接截图使用虚构测试信息，不代表该种子真实存在或可连接。

## 1. 搜索关键词

在首页顶部的大号输入框写入影片或资源名称，点击旁边的“搜索”。右侧三点菜单可切换搜索引擎或配置自定义搜索地址。

![首页](screenshots/01-home-keyword.png)
![输入关键词](screenshots/02-keyword-entered.png)
![搜索引擎菜单](screenshots/03-engine-settings.png)

## 2. 在首页查看搜索结果

搜索开始后，状态和结果都显示在首页“磁力搜索结果”区域。内置引擎包括 clg.im、BT搜索（dobt）、BD电影首发站、Pomo、美剧粉、高清族及原有引擎。应用会提取当前搜索页中的 magnet，并继续扫描最多 12 个同站搜索结果详情页；识别到磁力链接时，每条结果会显示文件名、链接以及“解析 / 播放”“下载 / 缓存”操作。自定义地址可用 `%s` 表示关键词。

如果搜索站点没有返回 magnet 链接，页面会说明当前状态，并提供大号“返回搜索”和“打开搜索网站”按钮。可从网站复制完整 magnet 链接，再回首页粘贴。搜索不会把你留在没有返回入口的空白页面。

![首页内搜索状态](screenshots/04-in-app-results.png)

## 3. 粘贴磁力链接

向下滚动到“粘贴磁力链接”卡片，粘贴以 `magnet:?xt=urn:btih:` 开头的完整地址，再点“解析资源”。

![粘贴磁力链接](screenshots/05-magnet-pasted.png)

## 4. 预览、下载或播放

解析页会显示连接状态、下载进度、速度和做种者数量。获取种子文件信息后，可选择预览、下载或播放。连接超过 45 秒仍未取得元数据时，页面会显示超时提示和“返回搜索结果”按钮。

![解析与下载状态](screenshots/06-torrent-progress.png)

## 5. 下载任务和收藏

底部“下载”显示本机已开始的下载任务及当前记录的进度；“收藏”显示你在资源解析/播放页点击收藏的资源。点击收藏条目可再次打开资源。

当前版本的下载需要任务页面和应用继续运行，不承诺退出后的后台续传。任务记录、收藏以及下载的文件均保存在应用专属数据中；清除数据或卸载会删除它们。

## 6. 实测说明和故障处理

实测时 clg.im 返回验证页，mg.dobt.cc 首页未提供可识别 magnet；BD电影首发站和 Pomo 可返回“哪吒”结果，相关 magnet 位于详情页，抓取逻辑已覆盖这种页面结构。你发来的 magnet 中 39 位十六进制主体后接 `&#x30;`（字符 0）及 Markdown 尾缀；应用会先解码并规范化 BTIH。当前尚未验证该哈希能否连接到在线种子，也尚未完成播放和下载闭环；搜索站可访问性、tracker / DHT 网络和做种者状态都会影响实际结果。

如果种子元数据 45 秒内仍未出现，请返回检查 magnet 是否完整，或确认 tracker、DHT 与做种者可连接。没有在线节点时，应用不能生成种子文件列表。

- Android 7.0（API 24）及以上，适配手机、平板和 Android TV。
- 播放和下载自动选择种子中的最大文件。
- 只下载和播放你有权使用的内容。
