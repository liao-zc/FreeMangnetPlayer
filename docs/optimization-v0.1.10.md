# FreeMangnetPlayer v0.1.10 功能优化报告

日期：2026-10-29。本报告正在根据实际 APK 测试补充结果，尚未完成的测试不标记通过。

## 本轮改动

| 用户要求 | 实现方式 | 验证方法 |
| --- | --- | --- |
| 边下边播 | Media3 通过自定义数据源读取 libtorrent 已校验分片；请求视频头尾及当前读取位置附近分片 | 播放器实际播放时，验证已下载字节小于总字节；保存真实视频截图 |
| 暂停、取消与清空 | 暂停保留任务和文件；取消停止引擎并保留文件；清空停止引擎后删除任务专属目录 | 对比暂停和取消前后真实下载字节，检查清空后的目录已删除 |
| 后台下载 / 缓存 | Android dataSync 前台服务持有任务，页面退出不会停止下载；通知栏提供管理入口 | 返回搜索并按 HOME，检查下载字节继续增长和前台服务状态 |
| 多视频切换 | 文件列表及选择弹窗内可切换视频；释放旧播放器，按新文件的全局分片偏移读取 | 同一链接的两个真实视频切换后检查文件索引、播放状态和画面 |
| 优先使用已有文件 | 优先已有下载文件，再使用缓存文件；重新打开时由 libtorrent 重新校验，不读取未校验的空洞文件 | 完成下载后重启 APP，在自定义下载地址重新播放 |
| 单选 / 多选下载 | 勾选任意文件、全选或全不选；文件优先级一次性更新，正在播放的视频仍需缓存 | 检查选择集合，下载完成后逐个比对源文件 SHA-256 |
| 可配置存储地址 | 独立下载和缓存路径，保存前实际创建和删除测试文件；缓存转下载时迁移任务文件 | 从设置界面填写非默认目录，检查实际文件路径和内容 |
| 缩短首播等待 | 首先请求视频头部和尾部分片，数据源按读取位置及 seek 位置请求后续分片；降低播放器起播缓冲阈值 | 记录收到元数据、开始播放、下载完成的实际时间，不以假进度代替 |
| 设置入口与默认引擎 | 首页“设置”，保留六个内置引擎和一个自定义引擎；默认引擎持久保存 | 设置页保存后，在首页菜单及冷启动后检查配置 |
| 最大下载 / 缓存数量 | 限制同时下载任务数；超额排队；缓存超额清理最早使用且未打开的任务 | 实际多种子排队及缓存目录删除检查 |

## 操作流程

1. 打开 APP，点击首页“设置”，填写下载目录、缓存目录及任务数量，选择默认引擎，点击“保存设置”。
2. 返回首页，搜索关键词或粘贴磁力链接，进入资源解析页面。
3. 文件列表中勾选需要下载的文件。可打开“选择文件”，执行全选、全不选或切换播放某个视频。
4. 点击“▶ 播放”边缓存边播放；“预览”准备暂停的播放器；“下载”将所选文件加入下载并保存到配置的下载位置。
5. 点击“暂停下载”或“继续下载”；“取消下载”保留文件但停止任务；“清空文件”经确认后删除当前任务文件。
6. 返回首页“下载”查看真实任务，点击任务可重新进入管理页面。正常返回、按 HOME 和熄屏不会主动停止下载服务。
7. 设置页的“一键清空下载 / 缓存”只删除对应任务的专属文件。正在打开的资源会保留，请先返回再清理。

## 实际限制

- 磁力元数据和视频数据仍需要可连接的节点；不存在能使没有可连接做种者的资源自动可播的保证。低于视频码率的下载速度也可能造成缓冲。
- 路径可手动修改为应用有权写入的目录，也可选择设置页列出的应用存储位置。Android 公共目录受系统权限限制；本版不将 SAF 的 `content://` 目录冒充 libtorrent 可直接写入的文件路径。
- 最大下载数量指同时传输的任务数，包含视频缓存；最大缓存数量指缓存任务数，并非视频字节数。正在播放的视频即使未勾选下载，也必须缓存所需分片。
- Android 15 对后台 dataSync 前台服务有每日六小时的系统限额；到限额后保存任务并暂停。系统强制停止 APP、撤销存储权限、取出存储卡或厂商省电限制，也可能中断后台任务。
- 新版本使用固定发布签名；此前 v0.1.9 的临时调试签名无法恢复，首次迁移可能需要卸载旧版本。卸载会删除应用数据，请先记录重要磁力和收藏。
- 本轮完整运行环境为 Android 35 手机模拟器；电视和平板不以手机模拟器测试冒充实机验证。
