# OmniPlayer

Android media player with IPTV live TV and the existing magnet search, playback, download, cache, and favorites features.

- Android display name: **OmniPlayer**
- Package ID remains `com.freemangnetplayer` to preserve installation identity and local app data.
- IPTV upgrade details and verification limits: [docs/iptv-upgrade-0.2.0.md](docs/iptv-upgrade-0.2.0.md)
- Chinese usage guide: [docs/usage-zh.md](docs/usage-zh.md)
- Existing magnet player verification report: [docs/report.md](docs/report.md)
- Third party notices: [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)

The IPTV default playlist is `https://iptv-org.github.io/iptv/index.m3u`. Channel availability and playback depend on each source and the device's codecs/protocol support.
