包含六个指定搜索引擎、自定义设置、两层搜索分页、磁力解析、缓存入口、按文件下载与删除、收藏和播放历史、已有数据的视频队列、双播放器及轨道画质选择。

低清仅选择已有视频轨道，单画质磁力不会因此减少下载流量。指定电影的立即起播和同设备对标仍未完成，见报告真实边界。
